# יומן החלטות וכלל ההתייעצות

## כלל ההתייעצות

**כל החלטה שמשפיעה על יותר מתפקיד אחד מקבלת המלצה מהגורמים הרלוונטיים לפני
שהיא נסגרת.** ההמלצות נרשמות בטבלה למטה. מחליט שהולך נגד המלצה — מתעד למה.

### מי מחליט ועם מי חובה להתייעץ

| סוג החלטה | מחליט | חובה להתייעץ |
|---|---|---|
| מוצר והתנהגות למשתמש (תוצאות, זרימות, מה נשמר) | אליה (והדס בקליני) | UX, קליני, משפטי, אבטחה, יעילות |
| תוכן קליני (תחום, דגלים, טבלת החלטה) | הדס | מנסח קליני, משפטי, מעצב שיחה, ארכיטקט |
| ארכיטקטורה וטכנולוגיה | ארכיטקט | אבטחה, יעילות; מבקר תכנון בהחלטות גדולות |
| נוסחים קבועים | מעצב שיחה | משפטי (⚖️), קליני (משמעות), UX (מיקום ואורך) |
| עיצוב ומסכים | UX / UI | נגישות, מעצב שיחה, frontend |
| פרטיות, נתונים, ספקים | אליה | אבטחה, משפטי |
| אנליטיקה, SEO, מדידה | אליה | SEO ואנליטיקה, אבטחה, משפטי |
| עלויות ותקציב (תקרות, תוכנית Netlify, ספק LLM) | אליה | ארכיטקט, יעילות, אבטחה |
| ניהול הצוות (מודל, מקביליות, חידוש מול מופע חדש, רשימות קריאה, סדר סבבים, דילוג על סבב) | מנהל | **יעילות — תמיד**; ובמה שנוגע לאיכות — בעל התחום |

### איך מתייעצים (בזול)

- בקשה קצרה עם **רשימת קריאה**. תשובה עד 150 מילים לכל החלטה:
  **ממליץ / מתנגד + נימוק / אין עמדה**, ותנאים אם יש.
- **מאגדים:** כל ההחלטות הפתוחות לתפקיד אחד — בבקשה אחת לסבב.
- **סף:** החלטה בתוך התחום של תפקיד אחד, הפיכה, שלא משפיעה על אחרים — לא דורשת
  התייעצות; היא נרשמת בתוצר של אותו תפקיד.
- **התנגדות בטיחותית** (קליני / משפטי / אבטחה) לא מוכרעת ע"י המנהל — היא עולה
  לאליה או להדס עם שתי העמדות זו לצד זו.
- התייעצות היא **לפני** החלטה; ביקורת היא **על** תוצר. אחת לא מחליפה את השנייה.
